在线体验 初始化…

当前是本地双击打开（file://），浏览器会禁止网页处理本地视频的音频，内置延迟没有声音。 请用在线版，或在本目录运行 npx serve / python -m http.server， 再访问 http://localhost:3000 这样的本地地址。

右下角就是扩展同款面板，已经内置在这页里 —— 不用安装，点播放后直接拖。

  1. 点播放，让视频先出声
  2. 拖面板滑块（或滚轮、←→）让声音变晚或提前
  3. 点归零，声音重新和口型对上

面板和延迟链路都来自扩展本身，区别只是这里处理的是本页视频的声音。 想调节任意网站、任意播放器，再装扩展：Edge 加载项商店 · 从源码安装。
装了扩展后请把这里的值归零，避免两段延迟叠加。这页是完整的本地文件，双向模式（让声音提前）需要边下边播的流媒体，所以这里只演示延后。
